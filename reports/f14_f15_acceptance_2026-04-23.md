## 2. Code-shape sanity check

All four expected structural changes are present in the code:

- `common/gnps_loader.py` — `iter_records(path)` now dispatches on
  `Path(path).suffix.lower()`:
    - `.json` → `_iter_records_json` (original body preserved)
    - `.mgf` → new `_iter_records_mgf` (streams BEGIN IONS / END IONS
      blocks, uses shared `_parse_*` / `_normalise_adduct` helpers)
    - `.csv` → raises `ValueError("… is a CSV metadata file with no
      peak column …")`
    - any other suffix → `ValueError("Unsupported GNPS dump extension…")`

- `tools/library_search/tool.py`:
    - new `GNPS_SPECTRA_PATH_ENV = "METAGENT_GNPS_SPECTRA_PATH"`
      constant next to the existing `GNPS_PATH_ENV`
    - `_load_gnps_records` looks up the spectra path from the new env
      var, falls back to deriving `.mgf` from a `.csv` value of
      `METAGENT_GNPS_PATH` if present, and honours `required=False`
      (logs a warning and returns `None` instead of raising)

- `tools/candidate_prefilter/env.sh` — adds
  `METAGENT_GNPS_SPECTRA_PATH=${_DATA_ROOT}/gnps/ALL_GNPS_cleaned.mgf`
  and extends the sanity-check loop to include it.

- No changes outside the five allowed files (`tools/candidate_prefilter/
  gnps_index.py`, `schemas/`, `docs/`, other tracks' directories all
  untouched — verified via `git show --stat 411e5a9`).

## 4. Before/after comparison (the point of the whole exercise)

Same input (glucose fixture, 30-candidate slice of A2's 205-candidate
pool), same ms-clip checkpoint, same GNPS dataset. The only variable
is whether the modcos path was exercised.

| Variant | top-1 | top-2 | top-3 | Reached via |
|---|---|---|---|---|
| `libraries=["inhouse"]` workaround (pre-F14/F15) | TAGATOSE 0.726 | FRUCTOSE 0.714 | SORBOSE 0.713 | ms-clip only |
| `libraries=["inhouse","gnps"]` (post-fix) | **β-D-Allose 0.789** | **D-Fructose 0.771** | TAGATOSE 0.726 | ms-clip ∪ modcos |

Observations:

- The two new top entries (0.789 and 0.771) are both `"Spectral Match
  to …"` GNPS library records — these are the ones where modcos found
  real peak-alignment signal. They outrank every ms-clip-only result,
  which is the expected behaviour: modcos sees the actual query peaks
  against a real reference, ms-clip only sees SMILES embeddings.
- ms-clip alone cannot distinguish stereoisomers of glucose (TAGATOSE,
  FRUCTOSE, SORBOSE all come back ≈ 0.72 because they share the same
  stereo-stripped SMILES in GNPS). modcos provides the missing
  discriminator.
- No candidate is lost. Bottom of the top-5 is unchanged
  (MYOINOSITOL 0.697 in both runs).
